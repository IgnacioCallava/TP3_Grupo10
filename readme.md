# 🚗 Autos de Elite

## 📌 Descripción

**Autos de Elite** es una página web desarrollada como parte del Trabajo Práctico N°1 de la materia Programación 3.
El proyecto fue realizado utilizando **HTML y CSS básico**.
El objetivo principal fue practicar la estructura de páginas web y estilos básicos, aplicando conceptos fundamentales de desarrollo frontend.

---

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3

---

## 📄 Páginas del sitio

El sitio está compuesto por las siguientes secciones:

* 🏠 Home (`index.html`)
* 📞 Contacto
* 👥 Equipo
* ❓ FAQ (Preguntas Frecuentes)
* 📝 Pedido
* 🛠️ Servicios

---

## ⚙️ Estructura del proyecto

El proyecto se organiza de la siguiente manera:

```
📁 Assets/
   ├── img/
   └── iconos/

📁 css/
   └── style.css

📁 pages/
   └── (todas las páginas secundarias)

📄 index.html
📄 README.md
```

---

## 🚀 Cómo ejecutar el proyecto

1. Clonar el repositorio:

   ```
   git clone https://github.com/IgnacioCallava/TP1_Grupo10.git
   ```

2. Abrir la carpeta del proyecto.

3. Ejecutar el archivo `index.html` en cualquier navegador web.
